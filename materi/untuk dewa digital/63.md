Tombol ini bisa berubah tergantung status repositorimu:

| Tulisan Tombol                | Arti                                          | Tindakan                          |
| ----------------------------- | --------------------------------------------- | --------------------------------- |
| **Publish repository** (biru) | Repo belum diupload ke GitHub                 | Klik untuk mengunggah ke GitHub   |

| **Fetch origin** (abu-abu)    | Sudah sinkron, tidak ada perubahan            | Tidak perlu diklik                |
| **Publish branch**            | Kamu menambah branch baru, tapi belum dikirim | Klik untuk kirim branch ke server |

Jadi kalau **tidak ada “Push origin”**, kemungkinan besar masih di tahap **belum Publish**, jadi tombol yang muncul adalah **Publish repository**.

# A. Cek dan publish repo (GitHub Desktop + Git)

**GitHub Desktop — cepat:**

1. Buka GitHub Desktop → pilih repo `Tuhan-Digital`.

2. Lihat kanan atas:
   
   - Kalau ada **Publish repository** → klik → isi nama → pilih Public/Private → Publish.
   
   - Kalau ada **Push origin** → klik untuk upload commit yang tertunda.

3. Untuk memeriksa remote: menu **Repository → Repository settings** → lihat `Remote` — harus ada URL seperti `https://github.com/WindyMoney/Tuhan-Digital.git`.

**Jika kamu nyaman pakai terminal (CMD/PowerShell) — jalankan di folder repo:**

`git status git branch -vv git remote -v`

- Kalau `git remote -v` belum ada, tambahkan:

`git remote add origin https://github.com/WindyMoney/Tuhan-Digital.git git branch -M main git push -u origin main`

> Jika diminta *username/password*, gunakan **Personal Access Token (PAT)** sebagai password.

---

# B. Perkuat keamanan GitHub (penting)

1. **Aktifkan 2-Factor Authentication (2FA)** di GitHub (Settings → Security → Two-factor authentication).

2. **Periksa dan cabut token / aplikasi OAuth** yang tidak dikenal: Settings → Developer settings → Personal access tokens + Applications → Authorized OAuth Apps.

3. **Revoke PAT lama** bila ragu, buat PAT baru hanya dengan scope yang perlu.

4. **Periksa sessions & devices**: Settings → Security → Sessions — logout sesi yang asing.

5. Untuk repo private: atur Collaborators → hanya akun tepercaya.

---

# C. Perkuat keamanan PC (Windows contoh)

1. **Update OS & aplikasi** (Start → Settings → Update & Security).

2. **Gunakan antivirus/antimalware up-to-date** (Windows Defender aktif jika tidak pakai pihak ketiga).

3. **Matikan/lock remote access** kalau tidak dipakai:
   
   - Non-aktifkan RDP: Settings → System → Remote Desktop (off).
   
   - Periksa apakah ada AnyDesk / TeamViewer terpasang; hapus atau set password kuat.

4. **Cek program startup / terpasang**: Task Manager → Startup; Settings → Apps → Installed apps.

5. **Periksa koneksi mendengarkan (port open)**:
   
   - Buka PowerShell as Admin:
     
     `netstat -ano | findstr LISTENING`
     
     lihat proses mencurigakan.

6. **Ganti password router + gunakan WPA2/3**, jangan pakai password default.

7. **Gunakan account Windows non-admin** untuk harian; admin hanya saat perlu.

8. **Backup & encrypt** file sensitif (mis. .env, json kunci) — simpan backup offline.

---

# D. Cek indikasi kompromi (cek cepat)

- Adakah software remote yang nggak kamu instal? (AnyDesk, TeamViewer, Chrome Remote Desktop)

- Proses CPU/network abnormal di Task Manager?

- Login GitHub dari device/location asing? (GitHub Settings → Security → Sessions)

- File .ssh atau keys aneh? (`C:\Users\<you>\.ssh`)

- Adakah commit atau perubahan di repo yang kamu tidak lakukan?

---

# E. Praktik aman untuk repo (git)

- Masukkan file sensitif ke `.gitignore` sebelum commit (contoh `.env`, `*.json` kunci).

- Jika tak sengaja commit file sensitif → lakukan rotate/revoke credential (mis. firebase key) dan hapus commit (history) dengan hati-hati.

- Jangan commit `config.py` yang berisi secrets.

Contoh `.gitignore` singkat:

`# Python __pycache__/ *.py[cod] *.so  # Env .env config.py *.sqlite3 # Firebase / keys google-services.json *sahabat-sehat-*.json`
