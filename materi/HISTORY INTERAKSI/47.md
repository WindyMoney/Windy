Nah, ini juga sering bikin bingung 🙂.

Di MT5 ada **2 level izin Algo Trading**:

---

### 1. **Level Global (Umum, untuk semua EA di semua chart)**

- Tombol **Algo Trading** di toolbar utama platform (ikon segitiga hijau).

- Kalau ini **OFF (merah silang)** → semua EA tidak bisa trading otomatis, meskipun di input / setting EA dicentang.

- Kalau ini **ON (hijau)** → barulah EA *mungkin* bisa trading, tergantung izin per-EA.

---

### 2. **Level Per-EA (khusus tiap EA di chart)**

- Saat pertama kali attach EA ke chart, di tab **Common** ada checkbox:  
  👉 **“Allow Algo Trading” / “Izinkan Algo Trading”**.

- Ini berfungsi **membatasi EA tertentu**. Jadi meskipun global Algo Trading aktif, tapi kalau di EA ini checkbox tidak dicentang → EA tersebut **tidak boleh melakukan trade otomatis** (hanya bisa analisa/indikator).

- Sebaliknya, kalau dicentang → EA ini punya izin untuk buka/modify/close order sesuai logikanya.

---

### Jadi maksudnya:

- **Global Algo Trading = master switch** → mematikan/menyalakan semua EA.

- **Per-EA Allow Algo Trading = izin spesifik** → mematikan/menyalakan EA tertentu.

📌 Contoh:

- Algo Trading global = ON ✅

- EA1 → Allow Algo Trading = ON ✅ → bisa trading

- EA2 → Allow Algo Trading = OFF ❌ → hanya jalan analisa, tidak buka order

// ---------------- MANAGE TRAILING PER SYMBOL ----------------
void ManageTrailingForSymbol(string sym)
{
 // iterate positions and handle
 for(int i=PositionsTotal()-1; i>=0; i--)
 {
 ulong ticket = PositionGetTicket(i);
 if(ticket==0) continue;
 if(!PositionSelectByTicket(ticket)) continue;
 string psym = PositionGetString(POSITION_SYMBOL);
 if(psym != sym) continue;
 int type = (int)PositionGetInteger(POSITION_TYPE);
 double open = PositionGetDouble(POSITION_PRICE_OPEN);
 double curSL = PositionGetDouble(POSITION_SL);
 double price = (type==POSITION_TYPE_BUY) ? SymbolInfoDouble(sym,SYMBOL_BID) : SymbolInfoDouble(sym,SYMBOL_ASK);
 double point = SymbolInfoDouble(sym,SYMBOL_POINT);
 double profitPoints = (type==POSITION_TYPE_BUY) ? (price - open)/point : (open - price)/point;
 // set initial SL if none
 if(curSL==0.0)
 {
 double initSL = (type==POSITION_TYPE_BUY) ? (open - InitialSLPoints*point) : (open + InitialSLPoints*point);
 initSL = NormalizeDouble(initSL, (int)SymbolInfoInteger(sym,SYMBOL_DIGITS));
 SafeModify(ticket, sym, type, initSL, 0.0, price, curSL, "INIT_SL");
 }
 // lock first when profit >= MinProfitToStartTrail
 if(profitPoints >= MinProfitToStartTrail)
 {
 double cand = (type==POSITION_TYPE_BUY) ? (price - LockDistance*point) : (price + LockDistance*point);
 cand = NormalizeDouble(cand, (int)SymbolInfoInteger(sym,SYMBOL_DIGITS));
 if((type==POSITION_TYPE_BUY && cand > curSL + TrailStepPoints*point) ||
 (type==POSITION_TYPE_SELL && (curSL==0.0 || cand < curSL - TrailStepPoints*point)))
 {
 SafeModify(ticket, sym, type, cand, 0.0, price, curSL, "LOCK20_FIRST");
 }
 }
 // dynamic step trailing
 double dyn = (type==POSITION_TYPE_BUY) ? (price - LockDistance*point) : (price + LockDistance*point);
 dyn = NormalizeDouble(dyn, (int)SymbolInfoInteger(sym,SYMBOL_DIGITS));
 if(type==POSITION_TYPE_BUY)
 {
 if(dyn > curSL + TrailStepPoints*point) SafeModify(ticket, sym, type, dyn, 0.0, price, curSL, "DYN_STEP");
 }
 else
 {
 if(dyn < curSL - TrailStepPoints*point) SafeModify(ticket, sym, type, dyn, 0.0, price, curSL, "DYN_STEP");
 }
 }
}
