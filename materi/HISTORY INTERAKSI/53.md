## 📂 Skema Database (SQLite)

### 1. **Tabel Pasien (`patients`)**

| Kolom          | Tipe Data   | Keterangan                        |
| -------------- | ----------- | --------------------------------- |
| id             | INTEGER PK  | ID unik pasien                    |
| nama           | TEXT        | Nama pasien                       |
| umur           | INTEGER     | Umur pasien                       |
| keluhan        | TEXT        | Keluhan utama                     |
| no_hp          | TEXT UNIQUE | Nomor HP pasien (unik untuk cari) |
| tanggal_daftar | DATE        | Tanggal pertama masuk             |

---

### 2. **Tabel Booking / Riwayat Bekam (`bookings`)**

| Kolom           | Tipe Data  | Keterangan                                |
| --------------- | ---------- | ----------------------------------------- |
| id              | INTEGER PK | ID booking unik                           |
| patient_id      | INTEGER FK | Relasi ke `patients.id`                   |
| tanggal_booking | DATE       | Tanggal booking                           |
| jam_booking     | TEXT       | Jam (misal: "09:00")                      |
| status          | TEXT       | `selesai` (sudah bekam), `batal`, `belum` |

---

### 3. **Tabel Broadcast / Jadwal Pesan (`messages`)**

| Kolom         | Tipe Data  | Keterangan                     |
| ------------- | ---------- | ------------------------------ |
| id            | INTEGER PK | ID pesan unik                  |
| jenis         | TEXT       | `pengingat` / `sunah` / `tips` |
| judul         | TEXT       | Judul pesan                    |
| isi           | TEXT       | Isi pesan                      |
| tanggal_kirim | DATE       | Kapan dikirim                  |
| status        | TEXT       | `terjadwal`, `terkirim`        |

## 🔄 Alur Fitur

### 🟢 1. **Pencarian & Booking**

- Input **no HP** → cek di `patients`.

- Jika ada → langsung isi jadwal (`bookings`).

- Jika tidak ada → isi data pasien baru → lanjut booking.

---

### 🟢 2. **Laporan Bulanan**

- Query: tampilkan **semua pasien yang sudah bekam** dalam bulan tertentu.
  
  `SELECT p.nama, p.no_hp, b.tanggal_booking  FROM patients p JOIN bookings b ON p.id = b.patient_id WHERE strftime('%m-%Y', b.tanggal_booking) = '09-2025'   AND b.status = 'selesai';`

- Pasien **yang tidak melakukan bekam** bulan itu:
  
  `SELECT nama, no_hp  FROM patients  WHERE id NOT IN (  SELECT patient_id   FROM bookings   WHERE strftime('%m-%Y', tanggal_booking) = '09-2025'     AND status = 'selesai' );`

---

### 🟢 3. **Broadcast WhatsApp**

- **Pengingat** → kirim ke pasien berdasarkan `tanggal_booking` terakhir + interval (misal 1 bulan).

- **Bekam Sunah** → broadcast ke semua pasien sesuai jadwal sunnah (misal: 17, 19, 21 bulan hijriyah).

- **Tips Sehat** → broadcast ke semua pasien (manual / jadwal).

> 📌 Untuk WhatsApp, kita bisa mulai dari **API resmi (Meta WhatsApp Business)** atau cara ringan **link wa.me** (manual klik).  
> Kalau kamu mau otomatis penuh → perlu **WhatsApp gateway** (contoh: WATI, Twilio, UltraMsg, atau buat bot pywhatkit/selenium).
