## **1. Versi Android murni (APK) dengan Kivy / Python**

**Kivy** adalah framework Python yang bisa membuat aplikasi **cross-platform**, termasuk Android. Dengan Kivy kita bisa buat APK langsung dari kode Python.

**Kelebihan:**

- Bisa dijalankan langsung di Android tanpa harus install Python secara manual.

- Tampilan GUI fleksibel (buttons, text input, calendar, list, dsb).

- Bisa offline sepenuhnya.

- Bisa di-packaging jadi APK menggunakan **Buildozer** (Linux) atau **Pydroid + Buildozer** di Android.

**Kekurangan / hal yang perlu diperhatikan:**

- Butuh setup awal Buildozer atau lingkungan Linux/WSL untuk compile APK.

- Beberapa modul Python (misal requests untuk internet, sqlite3 untuk database) perlu di-include secara eksplisit di buildozer.spec.

- Tidak se-native Kotlin/Java, jadi beberapa performa tinggi mungkin lebih lambat sedikit.

**Contoh alur app Kivy APK:**

`app.py │ ├─ data/ │    └─ tips_sehat.db ├─ kv/           (file .kv untuk layout) │    └─ main.kv └─ images/      └─ icon.png`

- `app.py` → logic utama

- `.kv` → layout GUI

- `tips_sehat.db` → database SQLite lokal

---

## **2. Database lokal (SQLite)**

SQLite adalah database ringan, file-based, cocok untuk aplikasi offline. Semua data disimpan dalam **satu file `.db`** yang bisa diakses langsung dari Python.

**Kelebihan:**

- Tidak butuh server online.

- Cepat dan ringan.

- Cocok untuk menyimpan pasien, jadwal, tips sehat, riwayat bekam.

**Contoh tabel:**

`-- Tabel pasien CREATE TABLE pasien (     id INTEGER PRIMARY KEY AUTOINCREMENT,     nama TEXT,     kontak TEXT,     tanggal_terakhir_bekam DATE,     keluhan TEXT );  -- Tabel tips CREATE TABLE tips (     id INTEGER PRIMARY KEY AUTOINCREMENT,     judul TEXT,     isi TEXT );  -- Tabel jadwal tips CREATE TABLE jadwal_tips (     id INTEGER PRIMARY KEY AUTOINCREMENT,     pasien_id INTEGER,     tips_id INTEGER,     tanggal_kirim DATE,     dikirim BOOLEAN DEFAULT 0 );`

**Kelebihan kombinasi Kivy + SQLite:**

- GUI interaktif & modern.

- Semua data pasien & tips tersimpan aman di HP.

- Bisa otomatis kirim notifikasi lokal berdasarkan jadwal.

''', (nama, kontak, tanggal_terakhir, keluhan))     conn.commit()     conn.close()`
