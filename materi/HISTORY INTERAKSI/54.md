# Gambaran arsitektur (pilihan yang praktis)

1. **Hybrid (direkomendasikan untuk awal — gratis, mudah di-deploy)**
   
   - **APK (Kivy)** — antarmuka input data pelanggan, tabel isi pesan (header + kolom1..n), pengelolaan jadwal bekam (tanggal terakhir), dan tombol sinkron/upload CSV/JSON ke server lokal / PC.
   
   - **Server kecil / PC (Windows/Linux) atau Raspberry Pi** — menjalankan skrip Python yang membaca tabel (CSV/SQLite) dan melakukan broadcast WhatsApp via `pywhatkit` atau `Selenium` pada jadwal (mis. tiap hari jam 10).
   
   - Keuntungan: APK tetap offline & gampang dibuat pakai Kivy (sesuai preferensimu), pengiriman WA dilakukan oleh PC/raspi -> tidak perlu API berbayar.
   
   - Catatan: WhatsApp automation via Web berisiko dibatasi oleh WhatsApp jika dianggap spam; harus gunakan dengan bijak.

2. **Semua di HP (Termux + Python)** — mungkin, tapi **rentan & rumit** (Chromedriver di Android, session, background service). Tidak direkomendasikan untuk stabilitas.

3. **Solusi resmi/andalan (berbayar)**
   
   - **WhatsApp Business API (Meta) / Penyedia seperti Twilio** — andal, skala, tapi berbayar dan proses pendaftaran. Cocok kalau mau bisnis serius nanti.

# Opsi gratis & trade-off

- **pywhatkit** (gratis, gampang): panggilan cepat `pywhatkit.sendwhatmsg()` membuka WhatsApp Web di browser dan mengirim. Kelebihan: sederhana. Kekurangan: bergantung pada sesi WhatsApp Web aktif, jadwal harus tepat, kadang butuh interaksi manual jika QR expired.

- **Selenium + ChromeDriver** (gratis, powerful): otomatisasi WhatsApp Web dengan kontrol penuh (bisa kirim ke banyak nomor, attachment, broadcast ke grup). Kelebihan: lebih fleksibel (bisa baca elemen HTML, handle multiple chats). Kekurangan: butuh setup Chromedriver, lebih rawan terdeteksi jika terlalu cepat/volume besar.

- **Telegram bot** (gratis, sangat stabil): API resmi bagus, tidak ada batasan semacam WhatsApp Web, lebih cocok untuk broadcast. Kalau audience mau/bersedia pakai Telegram, ini pilihan terbaik gratis jangka panjang.

# Risiko & aturan praktis

- Jangan kirim spam. Batasi jumlah broadcast per hari. Cantumkan opt-out (cara berhenti).

- WhatsApp bisa memblokir nomor yang terdeteksi bot/spam. Untuk percobaan kecil (daftar klienmu sendiri) umumnya aman jika tidak berlebihan.

- Pastikan WA Web login (QR) tidak di-share, dan simpan session cookie dengan aman.

- Jangan log nomor telepon, API key, token ke terminal. Simpan sensitif di file `.env` atau SQLite terenkripsi.

schedule daily broadcast jam 10:00     schedule.every().day.at("10:00").do(daily_broadcast)    # juga run weekly tips check jam 10     schedule.every().day.at("10:00").do(weekly_tips_run)    print("Scheduler started.
