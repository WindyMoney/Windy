`-- file: create_broadcast_tables.sql  CREATE TABLE users (   id INT AUTO_INCREMENT PRIMARY KEY,   username VARCHAR(100) UNIQUE,   password_hash VARCHAR(255),   role ENUM('therapist','admin') DEFAULT 'therapist',   phone_number VARCHAR(20) DEFAULT NULL );  CREATE TABLE fcm_tokens (   id INT AUTO_INCREMENT PRIMARY KEY,   user_id INT NULL,   token VARCHAR(512) NOT NULL,   device_info VARCHAR(255),   created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE SET NULL );  CREATE TABLE subscribers (   id INT AUTO_INCREMENT PRIMARY KEY,   phone_number VARCHAR(20) NOT NULL UNIQUE,   name VARCHAR(100) DEFAULT NULL,   subscribed BOOLEAN DEFAULT TRUE,       -- true = menerima broadcast   subscribed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,   unsubscribed_at TIMESTAMP NULL,   prefer_channel ENUM('app','wa') DEFAULT 'app', -- preferensi   notes TEXT );  CREATE TABLE broadcasts (   id INT AUTO_INCREMENT PRIMARY KEY,   title VARCHAR(255),   body TEXT,   affiliate_label VARCHAR(100),   affiliate_link TEXT,   therapist_phone VARCHAR(20),   scheduled_at DATETIME,   active BOOLEAN DEFAULT TRUE,   created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );  CREATE TABLE unsubscribes (   id INT AUTO_INCREMENT PRIMARY KEY,   subscriber_id INT,   reason VARCHAR(255) DEFAULT NULL,   created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,  FOREIGN KEY (subscriber_id) REFERENCES subscribers(id) ON DELETE CASCADE );`

# 2) Server module (FastAPI) — `broadcast_api.py` (lengkap, simpan)

Fungsi utama:

# 5) Cara menghindari blokir / keluhan (best-practices)

- **Double opt-in**: wajib jika kamu akan kirim via WA fallback. Jangan kirim ke nomor yang tidak setuju.

- **Batas frekuensi**: jangan kirim lebih dari 1-2 broadcast per hari; ideal 1 per hari atau beberapa kali seminggu.

- **Unsubscribe mudah**: selalu sertakan opsi UNREG (di app tombol jelas; di WA fallback berikan cara ketik 'STOP' atau link unsubscribe).

- **Sertakan identitas pengirim**: nama klinik, nomor yang jelas, dan link privacy policy.

- **Rate limiting & batching**: kirim notifikasi FCM dalam batch, jangan pukul semua token sekaligus (untuk menghindari throttle).

- **Gunakan FCM untuk in-app** (FCM tidak memblokir seperti WA). Hanya gunakan WA fallback untuk yang wajib.

- **Gunakan WhatsApp Business API** jika ingin kirim WA otomatis (memerlukan approval & template). Jangan automasi via WA Web scraping — itu rawan banned.
